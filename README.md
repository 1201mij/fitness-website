# 健身的真相 (The Truth About Getting Fit) - 網站專案

## 網站主題
本網站以「健身與運動」為主題，靈感來自於我對健身知識的自主學習紀錄。網站介紹了重訓、飲食、恢復等核心觀念，並推薦了多元的運動方式（如自由重量、公路車、籃球等），旨在幫助新手快速建立正確的運動觀念。

## 排版技術說明 (T02)
- **Flexbox 使用位置：** 應用於「三大核心觀念 (`#principles`)」區塊。透過 `display: flex` 與 `gap: 2rem`，讓三個觀念卡片在桌面版時水平等距排列 (`flex-direction: row`)。
- **Grid 使用位置：** 應用於「多元運動推薦 (`#exercises`)」區塊。使用 `grid-template-columns: repeat(2, 1fr)` 建立 2x2 的網格系統，讓四種運動項目能整齊劃一地呈現。

## 響應式設計與 Breakpoint (T05)
- **選擇斷點：** 我選擇 `768px` 作為 Breakpoint，因為這是多數平板直向與手機螢幕的交界值。
- **桌面版 vs 手機版差異：**
  - **桌面版 (>768px)：** 導覽列在左右兩側；Flexbox 區塊為橫向三欄；Grid 區塊為雙欄配置，充分利用大螢幕寬度。
  - **手機版 (<=768px)：** 螢幕寬度不足以並排內容，因此將 Flexbox 的 `flex-direction` 改為 `column`；Grid 的欄位改為 `grid-template-columns: 1fr` 變成單欄；導覽列也改為垂直置中，避免水平溢出（Overflow）導致使用者需左右滑動。

## AI 輔助與設計決策 (F07)
配色方面我自行決定採用深藍色 (`#2c3e50`) 搭配亮紅色 (`#e74c3c`) 點綴，營造專業且具有活力的健身氛圍。
在使用 AI 輔助時，AI 曾建議 Grid 區塊在桌面版使用 `repeat(4, 1fr)`（四欄並排），但經過我在瀏覽器實測後，認為四個卡片並排會導致內文過於擁擠、難以閱讀，因此我自行將程式碼調整為 `repeat(2, 1fr)`（雙欄配置），讓每個卡片有足夠的呼吸空間。
